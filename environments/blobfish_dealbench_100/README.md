# Description

DealBench-100: 100 stateful enterprise-operations tasks over 36 tools; SQLite-backed business systems with transactional writes and a full call trace; graded by a deterministic state-and-trace verifier with no LLM judge.

Each task drops the policy into an isolated company: 36 tools such as `benchmark__get_task, benchmark__get_submission, dealroom__search_files, dealroom__get_file, dealroom__get_version_history, dealroom__get_permissions`,
one assignment written the way a manager would write it, and world state that persists across the
episode. Grading is deterministic: the package's own verifier scores the final state and the call
trace (outcome, required investigation before writes, readbacks, containment of unrelated records).
Reward is the criterion fraction (`reward_mode: gated` scales it by the earned share of the
suite's outcome families); `strict_pass` requires every criterion and is rare by design, so the
dense fraction is the training signal.

# Example usage

Create an `env.yaml` in the Gym root with `policy_base_url`, `policy_model_name`, `policy_api_key`,
and `hf_token` (the train and validation splits resolve from Hugging Face).

## Getting the task packages

```bash
harbor datasets download blobfishai/dealbench-100 -o data/suites/dealbench-100
export BLOBFISH_DEALBENCH_100_DIR=$PWD/data/suites/dealbench-100/dealbench-100   # optional; this is the config default
```

Packages are executable code run in-process by the server; `data/suite_manifest.json` pins each
one to its reviewed SHA-256 and the server refuses to start on anything else.

## Running servers

```bash
gym env start --environment blobfish_dealbench_100 --model-type openai_model
```

## Collecting rollouts

```bash
gym eval run --no-serve --agent blobfish_dealbench_100_simple_agent     --input environments/blobfish_dealbench_100/data/example.jsonl     --output results/blobfish_dealbench_100_example_rollouts.jsonl --num-repeats 1
```

`data/example.jsonl` carries 5 validation rows; `data/example_rollouts.jsonl` is one
DeepSeek rollout per example row.
